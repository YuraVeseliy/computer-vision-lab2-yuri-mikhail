Изображение представлено списком строк. В строке лежат RGB-кортежи.
Поэтому `image[y][x]` — пиксель столбца x и строки y.
Я рассчитываю яркость, четыре гистограммы, статистику окна 11×11

### statistics_ops.py

| Функция | Параметры и результат | Что объяснить |
|---|---|---|
| `clamp(value)` | Число → целый канал 0..255 | Ограничение диапазона, округление `int(value+0.5)` |
| `intensity(pixel)` | RGB-кортеж → дробная яркость | Почему именно `(R+G+B)/3`, зачем `/3.0` |
| `intensity_matrix(image)` | RGB-массив → массив яркостей | Два вложенных цикла: по строкам и пикселям |
| `component_image(image, channel)` | Канал −1/0/1/2 → полутоновый RGB | −1 означает яркость, остальные индексы R/G/B; три одинаковых компоненты дают серый |
| `histograms(image)` | RGB-массив → четыре списка по 256 частот | Счётчик корзины увеличивается на один; все корзины суммарно дают число пикселей |
| `statistics(values, method)` | Значения → `(mean, variance, deviation)` | Две эквивалентные формулы, делитель N, корень через степень 0.5 |
| `window_values(image,x,y,size)` | Центр и размер → список яркостей | Радиус `size//2`, `range` не включает правую границу, обрезка у края |
| `row_profile(image,row_y)` | Номер строки → список I по всем x | Профиль — порядок значений, гистограмма — частоты без порядка |
| `demo_image()` | Без аргументов → учебный RGB-массив | Полосы периода 11 позволяют сравнить области с одинаковым средним |

Основные переменные: `image` — входной массив, `row` — строка,
`pixel` — RGB-кортеж, `result`/`result_row` — новые выходные списки,
`channel` — номер компоненты, `count` — число значений,
`total` — сумма, `square_total` — сумма квадратов,
`deviation_total` — сумма квадратов отклонений, `mean` — среднее,
`variance` — дисперсия, `radius` — половина стороны окна.
Типовые обозначения `x`/`column_x` — столбец, `y`/`row_y` — строка.

Пример: для `[2,4,4,4,5,5,7,9]` среднее 5, дисперсия 4, СКО 2.
Первый способ сначала ищет среднее, потом квадраты отклонений.
Второй в одном проходе накапливает сумму и сумму квадратов.
Ограничение отрицательной дисперсии нулём устраняет только погрешность
вычитания близких чисел типа float.

### image_io.py

`load_rgb(path)` проверяет фактический формат файла, а не только расширение,
режим RGB и глубину 8 бит. Для TIFF проверяет вид сжатия. `Image.open(path)`

`to_pillow(image)` создаёт `Image.new('RGB',(width,height))`, собирает строки
пикселей в плоский список и передаёт его `putdata`. Это упаковка уже
вычисленных значений для показа/сохранения, вычислений статистики здесь нет.

`save_rgb(image,path)` выбирает формат по расширению, проверяет его,
вызывает `save`. В массиве нет рамки: она нарисована только в Canvas.
`source` — открытая картинка Pillow; `target` — картинка для вывода;
`tags` — сведения TIFF; `bits` — глубины каналов; `suffix` — расширение.

`__init__(parent)` создаёт Canvas и две полосы прокрутки.

Профиль рисуется линией, шкала яркости фиксирована 0..255.

`left/top/right/bottom` — границы графика; `peak` — верхняя отметка;

### analysis_views.py

`build_notebook(app,parent)` создаёт пять вкладок и записывает ссылки на

В этом же файле находятся функции обновления представлений:

- `Canvas.create_image(x,y,image=...,anchor='nw')` размещает картинку;

- `configure(...)` задаёт свойства; `delete(tag)` удаляет элементы.
- `bind(sequence,handler)` связывает событие с обработчиком,

- `canvasx(x)`/`canvasy(y)` учитывают прокрутку Canvas.
- `ImageTk.PhotoImage(image)` переводит картинку в формат Tkinter.

Исходное изображение поэтому сохраняется для профиля и сброса.

### image_ops.py

| Функция | Параметры и результат | Что объяснить |
|---|---|---|
| `point_transform(image,operation,parameter,channel)` | RGB и настройки → новый RGB | Четыре формулы ниже; −1 выбирает все каналы |
| `swap_channels(image,first,second)` | Индексы каналов → новый RGB | Одновременная перестановка без потери значения |
| `mirror(image,horizontal)` | Ось отражения → новый RGB | `width−1−x` или `height−1−y` |
| `blur(image,connectivity)` | 4/8 → новый RGB | Центр включён, деление на реальное число точек, запись отдельно |
| `integral_image(values)` | Яркости → таблица накопленных сумм | Дополнительные нулевая строка и столбец упрощают границы |
| `contrast_map(image,neighborhood,size)` | 4/8/window → `(карта,среднее карты)` | Формула лекции, исключение центра, обработка границ |

Точечные формулы для компоненты c:

- Яркость: `c'=clip(c+Δ)`.
- Контраст: `c'=clip(μ+k(c−μ))`. При k=2 значение 100 при μ=125 становится
  75, а 150 становится 175. При k=0 всё становится μ; при k=1 не меняется.
  Для одного канала μ — его среднее; для всех RGB μ — средняя яркость.
- Негатив: `c'=255−c`; при инверсии всех RGB `I'=255−I`.
- Гамма: `c'=clip(255(c/255)^γ)`. Нормализация необходима, чтобы основание
  степени находилось в [0,1]. Поэтому γ>1 затемняет, γ<1 осветляет.

`operation` — строка с видом операции, `parameter` — число Δ/k/γ,
`center` — среднее для контраста, `index` — текущая компонента,
`output` — новые компоненты одного пикселя. `NEIGHBORS_4` содержит смещения
по сторонам, `NEIGHBORS_8` дополнительно содержит диагонали.
`dx/dy` — смещения, `nx/ny` — координаты соседей, `totals` — суммы RGB,
`count` — число существующих точек. При размытии есть смещение `(0,0)`;
при расчёте контрастности его нет.

Таблица сумм `S[y][x]` хранит сумму значений выше y и левее x,
то есть прямоугольник `[0,x) × [0,y)`. Для окна:

`sum = S[bottom][right] − S[top][right] − S[bottom][left] + S[top][left]`.

Две лишние области вычитаются; их общее пересечение было вычтено дважды,
поэтому прибавляется обратно. Затем вычитается центральный пиксель,
число соседей равно площади окна минус 1. Это ускорение суммы,
не готовая библиотечная функция обработки.

### application.py

`Application(root)` — объект состояния программы и обработчиков.
`original` — исходный массив, `current` — редактируемый,
`previous` — массив до последней операции для одной отмены.
Первоначально original и current ссылаются на одно изображение,
но алгоритмы его не изменяют: после операции current указывает на новый

показываются через `messagebox.showerror(title,message)`.

### editor_controls.py

`build_controls(app,parent)` создаёт поля и кнопки редактирования.
Кнопке передаётся **функция**, а не результат её немедленного вызова.
Поэтому `command=app.apply_swap`, без скобок.
Для функции с аргументом используется, например,
`command=lambda: app.apply_blur(4)`.
В цикле `lambda op=operation: ...` фиксирует текущее значение операции,
иначе все кнопки могли бы использовать последнее значение переменной.
`TYPE_CHECKING` нужен только для аннотации `Application` и предотвращает
циклический импорт при запуске; это не часть математики.

### main.py

`main()` создаёт `tk.Tk()` — главное окно; создаёт объект `Application(root)`;
запускает `root.mainloop()` — цикл ожидания и обработки событий.
Условие `if __name__ == '__main__'` запускает main при запуске файла,
а при импорте файла не открывает окно автоматически.

## Общие алгоритмы: повторяют оба

1. Яркость RGB и округление только для отображения/гистограммы.
2. Гистограмма: 256 счётчиков частот, отличие от профиля строки.
3. Среднее, дисперсия, СКО и два способа расчёта.
4. Центр окна, 11×11 и внешняя рамка 13×13, работа у края.
5. Все точечные преобразования, обмен каналов и зеркала.
6. 4-/8-связность, включение центра в размытие, новый выходной массив.
7. Карта C(p) и её отличие от дисперсии; таблица сумм для окна.
8. Различие исходного, текущего изображения и экранных элементов.

### Пример однородности

В учебном примере:

| Центр окна | Распределение 121 пикселя | μ | D | σ |
|---|---|---:|---:|---:|
| (64,48) | 121 значение 128 | 128 | 0 | 0 |
| (192,48) | 55 значений 28, 11 значений 128, 55 значений 228 | 128 | 100000/11 ≈ 9090.91 | ≈95.35 |

Среднее не отличает эти области. Однородность означает небольшие различия
значений внутри выбранного окна: узкая гистограмма и малая дисперсия.
Неоднородная область имеет значительный разброс или несколько групп
значений. Порог «малой» дисперсии зависит от изображения, шума и масштаба;
универсальное число из этих примеров не следует.
Гистограмма не показывает расположение пикселей: одни и те же частоты
могут соответствовать полосам, шахматному узору и другим рисункам.

### Контрастность — конкретный пример

У центральной точки I=100, у четырёх соседей 0, 200, 100, 100.
Их среднее 100, поэтому по формуле лекции C=|100−100|=0.
Среднее модулей разностей дало бы 50, но это **другая** формула.
При размытии центр вместе с этими соседями тоже дал бы среднее 100,
но размытие создаёт новые пиксели, карта контрастности — числа различий.

## Базовые знания из требований преподавателя

### Тригонометрия

В прямоугольном треугольнике: sin — противолежащий катет / гипотенуза,
cos — прилежащий / гипотенуза, tan=sin/cos, cot=cos/sin.
На единичной окружности cos — x, sin — y точки угла.
sin и cos принимают значения [-1,1]; tan и cot — любые действительные,
но tan не определён при cos=0, cot при sin=0.

`sin²α+cos²α=1`, `1+tan²α=1/cos²α`, `1+cot²α=1/sin²α`.
`sin(a±b)=sin(a)cos(b)±cos(a)sin(b)`.
`cos(a±b)=cos(a)cos(b)∓sin(a)sin(b)`.
`sin(2a)=2sin(a)cos(a)`, `cos(2a)=cos²a−sin²a`.
sin/cos имеют период 2π; tan/cot — π.
Радианы = градусы·π/180; градусы = радианы·180/π.

Обратные функции возвращают угол по значению:
arcsin: область [-1,1], диапазон [−π/2,π/2];
arccos: область [-1,1], диапазон [0,π];
arctan: область R, диапазон (−π/2,π/2);
arccot: область R, обычно диапазон (0,π).
Для arccot встречаются разные соглашения; здесь указано школьное.
Обратная функция — не то же самое, что `1/sin` или `1/cos`.

### Вероятность и статистика

Дисперсия — средний квадрат отклонений от среднего, измеряется
в квадрате единиц величины. СКО — её квадратный корень, в исходных единицах.
Для случайной величины `D(X)=E[(X−E[X])²]=E[X²]−E[X]²`.
Для значений изображения используем равные веса 1/N; в общем распределении
ожидание считают с вероятностями значений.
Постоянные значения имеют D=0. Среднее может быть одинаковым при разном D.
Два способа вычислить СКО: через квадраты отклонений или через
среднее квадратов минус квадрат среднего, затем извлечь корень.

### Алгебра

Если A размера m×n, B размера n×k, то AB размера m×k,
`(AB)[i][j]=Σ A[i][t]·B[t][j]` по t от 0 до n−1.
Нужно совпадение внутренних размеров. Умножение обычно некоммутативно:
AB и BA могут различаться или одно из них может быть не определено.
Оно ассоциативно: `(AB)C=A(BC)`.

Определитель определён для квадратной матрицы. Для 2×2:
`det([[a,b],[c,d]])=ad−bc`. Для 3×3:
`det([[a,b,c],[d,e,f],[g,h,i]])=a(ei−fh)−b(di−fg)+c(dh−eg)`.
При det=0 матрица необратима. Для преобразования плоскости модуль
определителя линейной части задаёт изменение площади;
отрицательный знак означает изменение ориентации.

### Математический анализ

Предел функции при x→a — число, к которому приближаются значения функции,
когда x приближается к a. Значение в самой точке может не совпадать
с пределом или вообще не быть заданным. Пример: sin(x)/x→1 при x→0.

Первая производная — мгновенная скорость изменения:
`f'(x)=lim[h→0](f(x+h)−f(x))/h`. Для x² это 2x.
Вторая производная — скорость изменения первой, для x² равна 2.
Для функции двух переменных градиент — вектор частных производных:
`grad f=(∂f/∂x,∂f/∂y)`. Для x²+y² это (2x,2y).
Он указывает направление наибольшего роста, его длина — величину роста
на единицу перемещения в этом направлении.
На изображении разности соседних значений приближают производные;
яркостный перепад связан с границами объектов.

### Программирование и ООП

Класс — описание данных и поведения, объект — конкретный экземпляр.
`ImagePanel` — класс, `app.viewer` — объект этого класса.
`self` — объект, для которого вызван метод; `__init__` его инициализирует.
Статический метод с `@staticmethod` не получает self автоматически;
его можно вызывать через класс. В этой программе отдельные расчётные
функции находятся на уровне модулей, статические методы не нужны.

Инкапсуляция — объединение состояния и действий, управление доступом.
В Python `_name` обычно означает внутреннюю часть по соглашению.
Наследование — создание класса на основе другого: `ImagePanel(ttk.Frame)`.
Полиморфизм — единый способ обращения к разным объектам, которые выполняют
действие по-разному. Например, два разных класса имеют метод `draw()`;
один рисует круг, другой прямоугольник, а вызывающий код одинаково делает
`shape.draw()`. Переопределение метода у наследников — один из механизмов.

Одномерный массив имеет один индекс, двумерный — два, трёхмерный — три.
Наш Python-список строк читается `image[y][x]`; каналы кортежа:
`image[y][x][channel]`. У обычного двумерного списка строки — отдельные
списки. Запись `[[0]*width]*height` опасна: все строки ссылаются на один
список. Поэтому в таблице сумм каждая строка создаётся отдельно.

Лямбда — небольшая безымянная функция-выражение:
`lambda x: x*x`. В кнопках она откладывает вызов функции до щелчка.
Список изменяем, кортеж RGB неизменяем, поэтому новые компоненты сначала
собираются в список, потом упаковываются в новый RGB-кортеж.

### Однородные координаты и зеркала

Точка (x,y) представляется как (x,y,1). Тройки (X,Y,W) и
(kX,kY,kW), где k≠0, представляют одну и ту же точку.
Если W≠0, обычные координаты — (X/W,Y/W).
Пример: (10,25,5) даёт (2,5). W=0 используется для точек на бесконечности
и направлений в проективной геометрии.

Для вектора-столбца (x,y,1) перенос на (tx,ty) задаёт матрица
`[[1,0,tx],[0,1,ty],[0,0,1]]`. Масштабирование:
`[[sx,0,0],[0,sy,0],[0,0,1]]`. Поворот:
`[[cos(a),−sin(a),0],[sin(a),cos(a),0],[0,0,1]]`.
На экранной сетке y направлена вниз, поэтому визуальное направление
поворота отличается от декартовой плоскости с y вверх.

Зеркало изображения слева/справа:
`[[-1,0,width−1],[0,1,0],[0,0,1]]`.
Сверху/снизу:
`[[1,0,0],[0,−1,height−1],[0,0,1]]`.
Сдвиг нужен, чтобы координаты после отражения остались внутри изображения.
При соглашении с векторами-строками используются транспонированные
матрицы. Если сначала применить A, затем B, для столбцов итог B·A.
